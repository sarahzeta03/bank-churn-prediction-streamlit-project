**Bank Churn Prediction – Streamlit App**

A web application that predicts whether bank customers are likely to churn or stay loyal based on their profile and activity data. Built with Streamlit and trained on the Churn_Modelling.csv dataset using Support Vector Machine (SVM) model.

🎉 **Live Demo**

Streamlit App: https://bank-churn-prediction-app-project.streamlit.app/](https://bank-churn-prediction-app-project-zamhq2orj8z792xbbmfdvt.streamlit.app/

Repository: https://github.com/sarahzeta03/bank-churn-prediction-streamlit-project

✨ **Features**

📊 **Interactive Input Form**:

Credit Score

Geography (France, Germany, Spain)

Gender

Age

Tenure

Balance

Number of Products

Is Active Member

Estimated Salary

🤖 **Machine Learning Model**:

Support Vector Machine (SVM)

⚙️**Preprocessing**:

One-hot encoding for Geography

Label encoding for Gender

Standard scaling for numeric features


📈 **Prediction Results**:

Binary prediction: Churn or Stay
Churn probability percentage
Visual dataset overview
